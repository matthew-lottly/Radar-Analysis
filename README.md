# Radar Analysis

Reproducible public-data radar studies with maps, transparent methods, and documented accuracy assessments.

## Projects

| Project | Data | Deliverables |
|---|---|---|
| [01 · Flood mapping: Spain, September 2019](projects/01-flood-mapping/README.md) | Sentinel-1, Sen1Floods11 hand labels, JRC permanent water | Water and potential-flood GeoTIFFs, polygons, error maps, accuracy audit, sensitivity analysis |
| [02 · Western Houston local deformation and GNSS audit](projects/02-subsidence-houston/README.md) | OPERA filtered LOS, archived UNR GNSS, EIA plants | Point maps, time series, infrastructure overlays, uncertainty and geometry checks; exploratory pilot |

Each project distinguishes measured results from unvalidated interpretations. See the project methods for reproduction commands and data attribution.
